## Convenciones de callouts

Usar bloques de cita Markdown con prefijo:

- `> 💡 **Tip** — ...` (consejo práctico)
- `> ⚠️ **Pitfall** — ...` (error común a evitar)
- `> 🎯 **Para tu proyecto** — ...` (puente al proyecto integrador)
- `> 📚 **Profundizar** — ...` (recurso opcional)
- `> ✅ **Checkpoint** — ...` (resultado esperado para autovalidación)

## Convenciones de figuras

- Numerar `Figura N: descripción`
- Toda figura externa debe llevar atribución al pie: `Fuente: [origen]`
- Figuras generadas con código del notebook: `Fuente: elaboración propia`

## Convenciones de código

- Bloques de código con lenguaje declarado (` ```python `)
- Anteceder cada bloque con `**Código N:** descripción`
- Si hay TODO para alumno, marcar con `# TODO ALUMNO: ...`
